# NETWORKWALKS B083 — Week 3 Cybersecurity Lab

## Overview

This repository documents my **NetworkWalks B083 Week 3 cybersecurity practicals**, focused on password security assessment and password-cracking techniques in controlled lab environments.

The work was completed for **learning and authorized cybersecurity training purposes**. The techniques demonstrated here are intended for systems and credentials where explicit permission has been granted.

## Week 3 Modules

### W3-PM1 — Password Cracking with John the Ripper

Practical work with **John the Ripper (JtR)** to understand how password hashes can be assessed against wordlists and cracking modes.

Key learning areas:

* Identifying password-hash material in a controlled lab
* Preparing hashes for password auditing
* Using wordlists and cracking modes
* Understanding successful and unsuccessful cracking attempts
* Interpreting cracking output
* Understanding why weak passwords are vulnerable to offline attacks
* Connecting password policy to practical security risk

### W3-PM2 — Password Cracking with NetworkWalks Tools

A second practical module covering password-security assessment using the tools and workflow provided by NetworkWalks.

Key learning areas:

* Password auditing workflow
* Hash and credential handling
* Tool-assisted password analysis
* Comparing approaches and results
* Documenting evidence from practical exercises

## Learning Objectives

By completing Week 3, I worked toward being able to:

1. Explain the difference between plaintext passwords and password hashes.
2. Describe how offline password cracking works.
3. Use John the Ripper in an authorized lab environment.
4. Understand the role of wordlists and password strength.
5. Interpret cracking results and failure conditions.
6. Document cybersecurity practical work clearly and reproducibly.
7. Recommend defensive controls such as strong password policies, password managers, MFA, secure hashing algorithms, salting, and rate limiting.

## Security & Ethics

All practical activities in this repository are for **authorized educational environments**.

Password-cracking techniques can be dual-use. They should only be applied to systems, credentials, hashes, or lab environments for which the tester has explicit permission.

No real-world credentials or unauthorized targets should be tested using these techniques.

## Takeaway

> Password security is not only about keeping passwords secret; it is also about making stolen password hashes difficult to recover.

Understanding the attack workflow helps security practitioners design stronger authentication controls and identify weaknesses before attackers exploit them.
